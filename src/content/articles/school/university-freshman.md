## ✅ 공통 — 상황 상관없이 필요한 것

### 노트북

대학 4년 동안 가장 많이 쓰는 물건입니다. 여기서 아끼면 4년 내내 불편해요.

**2026년 기준 최소 스펙:**
- RAM: **16GB 이상** (8GB는 크롬 탭 10개에서 버벅임)
- SSD: **512GB 이상**
- 무게: **1.5kg 이하** (매일 들고 다님)
- 배터리: **10시간 이상** (강의실 콘센트 없는 곳 많음)

**학과별 기준:**

| 학과 유형 | 최소 스펙 | 예산 |
|----------|----------|------|
| 문과·경영·사회 | RAM 16GB, SSD 512GB | 60~80만원 |
| 이공계·컴공 | RAM 16GB, SSD 512GB | 80~130만원 |

## ❌ 사지 말아야 할 것

| 항목 | 이유 |
|------|------|
| 교재 (입학 전) | 첫 주 수업 들어보고 구매. 교수가 "안 써도 됨" 하는 경우 많음 |
| 프린터 | 학교 도서관·복사실 장당 30~50원. 프린터 유지비가 더 비쌈 |
| 태블릿 | 노트북 있으면 당장 불필요. 한 학기 살아보고 진짜 필요할 때 구매 |
| 정장 | 입학식에 안 입음. 취업 준비 시작 때 사면 됨 |
| 교재 중고는 예외 | 에브리타임 장터, 학과 선배 물려받기로 50~70% 할인 가능 |
