# 휙 쇼츠 만들기

쇼츠 한 편 = 회차 하나의 품목 하나, 쿠팡 랭킹 TOP 3.

## 원칙
- 숫자만 말한다: 쿠팡 랭킹 순위, 리뷰 수, 가격. "추천", "최고", 효능 표현은 쓰지 않는다.
- 품목은 말해도 된다 ("처음엔 모래부터"). 상품은 늘 1·2·3위를 나란히 보여준다.
- 건강 관련은 효과를 말하지 않고, 복용 전 약사·의사 상담 문구를 넣는다.
- 글자는 안전 영역 안에만: x 56~940, y 220~1520 (`cfg.json`에 `"showSafe": true`면 빨간 점선).
- 영어 HWICK 대신 "휙".
- 사이트 회차와 쇼츠는 같은 날 공개한다 (회차 `published` 날짜).
- 늘 3편을 미리 만들어 두되, 그 이상은 당기지 않는다. 올리기 직전에 순위·리뷰 수·가격을 다시 확인하고, 차이가 크면 다시 만든다.

## 폴더
- `rank2.html` 랭킹 TOP 3 템플릿 (CFG·TLD를 주입받아 그린다)
- `<편>/cfg.json` 화면 문구·상품, `<편>/lines.json` 나레이션 7줄, `<편>/img/p1~3.jpg` 상품 사진
- `upload/<날짜>_<편>.md` 올릴 때 쓸 제목·설명·댓글 (댓글 링크는 쇼츠 전용 파트너스 링크)

## 만드는 순서
1. 나레이션: `.process/gen2.py lines-all.json tts2` (맥, ElevenLabs JY 보이스) → STT로 발음 확인
2. `python3 build_tl.py <편>` 타임라인
3. `python3 mix2.py <편> <BGM 시작초>` 음성·효과음·Suno BGM(`bgm/01b.wav`) 믹스
4. `python3 render3.py <편> safe` 미리보기 → `render3.py <편> full` 프레임 → ffmpeg로 합치기

## 올리는 날
1. 사이트 배포 (`npm run deploy`) — 그날 회차가 열린다
2. 스튜디오 업로드: 제목·설명, 아동용 아님, 유료 프로모션 표시, AI 변형 아님, 공개
3. 영상 페이지에서 댓글 달기 → 좋아요 → 소리 나기 전에 페이지 나가기
4. 댓글 고정은 채널 전화번호 인증 후 가능
